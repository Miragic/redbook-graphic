# redbook-graphic · 小红书图文一条龙

说一句「我要发篇小红书」，它给你文案 + 卡片 + 成品图，一步到位。

## 它帮你省掉的三件事

- 🖊 **不用憋文案** —— 5 个标题候选任挑 + emoji 短句正文 + 话题标签，小红书风格一次到位
- 🎨 **不用排版** —— 卡片一卡一页、编号体系清晰，默认小红书推荐 3:4 竖版，也支持 1:1 / 4:3 / 9:16
- 📱 **不用手动截图** —— 实拍图丢进 `images/` 自动填上留白位；没图就纯排版，照样能发

## 三个亮点

- **有实拍图**：截图位留白 + 文件名自动探测，图丢进去就生效，文件名带空格 / 错字也不怕
- **没实拍图**：纯文字 / 编号 / 图表排版，一样出成片，不用等补图
- **成品高清**：走「打印 PDF → 切图」链路，每张按所选尺寸精确输出（默认 1080×1440）

## 支持尺寸（默认 3:4）

| 预设 | 比例 | 输出 PNG（@2x） | 说明 |
|---|---|---|---|
| **3:4 竖版** | 3:4 | 1080×1440 | **小红书推荐，默认** |
| 1:1 方形 | 1:1 | 1080×1080 | 通用方图 |
| 4:3 横版 | 4:3 | 1440×1080 | 横版图文 |
| 9:16 全屏竖版 | 9:16 | 1080×1920 | 长图 / 全屏 |

切换尺寸：只改模板 `:root` 的 `--cw/--ch` 一处，`@page` 尺寸与缩放提示自动跟随。

## 安装

这是给 AI 助手（WorkBuddy）用的 skill。把整个目录复制到用户级 skills 目录即可：

```bash
cp -R redbook-graphic ~/.workbuddy/skills/
```

之后在对话里说「做一篇小红书图文」或「小红书那套流程」，助手就会自动加载它。

## 工作流

1. 确认有没有实拍截图（没有 → 纯排版；有 → 截图位留白）
2. 写文案（标题候选 + 正文 + 话题标签）
3. 排版卡片 HTML（基于 `assets/template.html`）
4. 交付 + 补图（仅截图版）
5. 导出成品图（打印 PDF → `scripts/export_cards.sh` 切图）

## 适合谁

- 想发小红书又懒得排版的
- 做工具 / 教程 / 测评 / 清单类图文的
- 有手机实拍截图想做成图文笔记的

## 触发词

小红书、图文笔记、发小红书、小红书配图、封面、话题标签、小红书文案、「小红书那套流程」；英文 redbook / RED 图文。

## 依赖

- 导出切图需要 poppler（提供 `pdftoppm`）：`brew install poppler`

## 目录结构

- `SKILL.md` —— 触发词 + 工作流 + 完成标准
- `assets/template.html` —— 可复用卡片模板（尺寸 CSS 变量驱动）
- `scripts/export_cards.sh` —— 打印 PDF → 高清 PNG 切图
- `references/card-spec.md` —— 版式规范 + 尺寸表 + 踩坑记录
- `references/examples.md` —— 完整案例「iPhone 记账系统」

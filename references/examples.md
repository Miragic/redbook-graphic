# 案例：iPhone 记账系统（不装 App 记账）

一个完整的「从需求 → 11 张卡 → 成品图」实例。写新主题时对照这个案例，看叙事结构怎么展开、截图位怎么留、文案怎么写。

## 需求

用户要发一篇小红书，讲「用 iPhone 自带功能（快捷指令 + Numbers + Scriptable）搭一套记账系统，不装任何记账 App」。用户会陆续补几张 iPhone 实拍截图。

## 产出物

- `小红书图文-记账系统.html` —— 11 张卡 + 内嵌文案区（单文件零外链）
- `小红书文案-记账系统.md` —— 标题候选 5 + 正文 + 标签 + 发布前检查 + CTA 三方案
- 导出 `小红书卡片/01~11.png` —— 每张 1080×1440

## 文案范例（实际交付内容）

**标题候选（5 个，各 ≤20 字）**
1. 不装App｜iPhone自带功能记账
2. 记账App全删了，换成iPhone原生方案
3. 3秒记一笔｜iPhone记账系统搭建
4. 不用会员也不看广告的记账法
5. 我搭了套iPhone记账系统，桌面就能看

**正文（约 480 字，emoji 起段 + 短句）**
```
记账 App 我下过一圈，最后全删了。

不是它们做得不好，是三个坎过不去：
① 记一笔要点 5 下 —— 开App → 选类型 → 填金额 → 选分类 → 保存
② 免费版有广告，想看报表就让你开会员
③ 数据存在别人的服务器上，哪天关服就没了

后来我换了个思路：用 iPhone 自带的两个东西，再加一个免费 App，拼了一套。

📱 三件套
· 快捷指令 —— 记账入口，挂在桌面或锁屏，点一下就开跑
· Numbers —— 账本就是一份普通文件，存在自己的 iCloud 里
· Scriptable —— 桌面小组件，抬头就能看到本月花了多少

⚡️ 记一笔的完整流程
1. 付款完成，随手截个图
2. 回桌面点快捷指令，它自己从截图里读出金额
3. 选一级分类 → 选二级分类
4. 问你要不要备注，不想写就跳过
5. 数据落进 Numbers，桌面小组件同时刷新

整个过程 3 秒左右，比开 App 快得多。
（中间按主题补分类/小组件/数据三小节，结尾给 CTA）
```

**话题标签（10 个）**
`#记账 #记账app #iPhone技巧 #快捷指令 #效率工具 #自我管理 #Numbers #Scriptable #极简生活 #工具分享`

## 这个案例踩出来的经验

1. **封面不放截图**：iPhone 截图是 1:2.17 竖长条，塞 3:4 要么裁要么看不清 → 封面用 CSS 画「示意」小组件卡当视觉锚点。
2. **账本截图露真实数字**：年度账本会露出「本年收入 ¥3,000.0 / 支出 ¥1,722.1 / 已记账 813 天」→ 出图前主动问用户「糊掉 / 裁掉 / 照发」，由用户拍板（本例用户选「照发」）。
3. **增卡时 `replace_all` 只改分母的坑**：从 9 张卡扩到 11 张时，全局替换 `/ 09` → `/ 11` 只改了分母，尾部两张卡的分子没跟着变（仍显示 08、09）→ 必须回头按 chip+badge 组合单独修。
4. **用户给的文件名不可控**：实拍图带空格、错字（「组件」写成「组价」）→ ALIAS 每条同时挂 原名 / 去空格 / `%20` 编码 三种写法，文件不用改名。
